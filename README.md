## 🚀 Featured Projects

### 🐧 ThakurOS — Custom Linux Distribution

**Arch Linux · archiso · Linux Kernel · Bash · systemd · GRUB · CI/CD**

- Built a bootable Arch-based Linux distribution with BIOS/syslinux and UEFI/systemd-boot support.
- Configured system users and permissions directly at the filesystem level.
- Automated system configuration and repeatable builds with idempotent shell scripts.
- Reduced manual rebuild time by approximately **90%**.

### 🤖 Sentinel.AI — Multi-Agent RAG System

**React · Node.js · Express.js · LangChain · FastAPI · Pinecone/Chroma · Hugging Face · OpenRouter**

- Built the frontend for a **Filter → Generator → Evaluator** multi-agent RAG pipeline.
- Worked with Llama, Claude and Gemini models through OpenRouter.
- Rebuilt the backend using LangChain LCEL, Hugging Face embeddings and a vector store.
- Implemented JWT-secured and Pydantic-validated API services with streaming responses.

### 📋 TaskFlow — Real-Time Collaborative Kanban

**React · Redux Toolkit · Node.js · Express.js · MongoDB · Socket.IO**

- Built a real-time Kanban board supporting **5+ concurrent users** with live task synchronization.
- Deployed the frontend on Vercel and the Socket.IO backend on Render.
- Configured production cross-origin WebSocket communication.
- Debugged API and database behavior to improve reliability and performance.

### 🛍️ Artisan's Corner — Indian E-Commerce Platform

**React · Redux Toolkit · Node.js · Express.js · MongoDB · Cloudinary · Razorpay**

- Built scalable REST APIs with JWT authentication and role-based access control.
- Added centralized error handling and production-oriented API structure.
- Integrated Razorpay payments and Cloudinary image uploads.
- Built an admin dashboard supporting **20+ product listings**.
